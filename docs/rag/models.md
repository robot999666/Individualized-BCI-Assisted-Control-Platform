# EEG、EOG与安全控制

## EEG如何工作
每窗501点、250Hz、约2秒。先做4–36Hz预处理，EA对齐校正个体协方差差异，FBCSP提取多个频带的空间特征，LDA输出四分类概率。无标签校准保存EA参考；有标签且每类至少10条时训练个人CSP/LDA。EA不等于重新训练分类器。前端显示真实预处理、特征提取、推理与端到端耗时，采集等待不算计算时间。

## EOG如何工作
真实SVM眨眼模型对250点微伏窗口做1–15Hz预处理，输出眨眼概率。有效EEG方向候选需两个不同眨眼峰确认。重叠窗口与已使用确认去重，候选改变重置确认状态。无眼电或眼电推理异常不生成移动确认。眨眼事件来自真实回放片段，不是按钮或计时动画生成。

## 安全判断
默认阈值55%、连续稳定2窗，管理员可调整新会话和重置后的参数。只有EEG稳定、置信度达标、EOG双眨眼确认、设备在线且预测未超时才放行方向命令。EEG停止则STOP，设备离线、错误、延迟超时、丢包或取消等均停止。记录命令来源、确认、执行状态、响应耗时。

## 人工干预与断线
人工急停停止所有设备并锁定会话，重置后才能开始。暂停STOP并冻结游标，继续从同一位置播放。重置清除游标、候选、确认和模拟姿态。关闭、退出、撤销或权限变化使旧推理失效。最后一个实时客户端断开会暂停并停止，watchdog兜底处理网络超时。智答不会发出设备命令。
