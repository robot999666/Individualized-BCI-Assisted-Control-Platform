# ALS-BCI 项目定位

## 项目目标
探索面向ALS等重度运动障碍人群的脑机辅助交互。运动想象EEG提出方向意图，EOG眨眼主动确认，结合人工急停和安全控制驱动模拟设备。当前为科研原型，未接真实硬件，不提供诊断、治疗或临床有效性结论。

## 四分类意图
左手运动想象对应左转LEFT，右手对应右转RIGHT，双脚对应直行FORWARD，舌头对应停止STOP，数字标签依次为0、1、2、3。EOG模型独立识别眨眼，不能把脑电分类概率当作眼电概率。

## 系统优势与证据
个体校准、真实信号回放、真实EEG与EOG模型、安全判断和设备回执在同一工作台展示。每窗显示概率、置信度、稳定次数、实际计算耗时和禁止执行的原因，运行中心记录命令、告警、处理时间。效率看真实毫秒指标；准确性需带标签且严格独立评测。T/E分离只保证此次校准与回放不混用；预训练模型的完整训练会话清单未知，不宣称独立泛化准确率或ALS临床有效性。

## 智答范围
BCI智答先用本地TF-IDF检索公开知识，再调用后端配置的deepseek-v4.1-flash组织回答，显示标题与章节。智答只能解释项目，不控制设备、不上传文件、不修改数据。问题与检索到的公开知识会发送给模型服务；EEG原始数据、档案和登录凭据不会作为上下文发送。未知内容应明确说明。
