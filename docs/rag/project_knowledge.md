# 个体化脑机辅助控制平台

## 项目目标
面向包括 ALS、重度脑卒中后遗症在内的重度运动障碍人群，提供个体化脑机辅助交互软件。运动想象EEG提出方向意图，EOG眨眼主动确认，结合人工急停和安全控制驱动模拟设备。平台覆盖个体化校准、信号回放、双模态确认、四类辅助设备仿真与运行追溯。

## 四分类意图
左手运动想象对应左转LEFT，右手对应右转RIGHT，双脚对应直行FORWARD，舌头对应停止STOP，数字标签依次为0、1、2、3。EOG模型独立识别眨眼，不能把脑电分类概率当作眼电概率。

## 系统优势与证据
个体化校准、EEG 与 EOG 信号回放、双模态模型、安全决策和设备回执在同一工作台同步展示。每个窗口呈现分类概率、置信度、连续稳定次数、各阶段计算耗时及执行条件，运行中心记录命令、告警、处理人与响应时间。支持 3 通道和 22 通道模型、四套内置来源及私有数据上传；校准档案可保存复用，模型版本与来源可追溯。带标签回放数据可查看本次评分。

## 实验指标说明
计算耗时按各处理阶段计量。回放评分针对当前带标签数据；独立泛化性能需使用与模型训练分离的评测数据。内置 T/E 数据分别用于校准与回放；预训练模型的完整训练会话清单未提供。当前平台以辅助交互软件与设备仿真展示为应用范围。

## 智答范围
BCI智答先用本地TF-IDF检索公开知识，再调用后端配置的deepseek-v4.1-flash组织回答，显示标题与章节。智答只能解释项目，不控制设备、不上传文件、不修改数据。问题与检索到的公开知识会发送给模型服务；EEG原始数据、档案和登录凭据不会作为上下文发送。未知内容应明确说明。
