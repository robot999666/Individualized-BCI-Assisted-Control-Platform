# 3D模拟设备演示

## 画面对应真实会话
复用轮椅、患者和脑电帽建模，展示轮椅、护理床、紧急呼叫、智能家居。读取当前会话服务器设备状态，只有执行成功并回执后姿态才改变。空间为演示单位，不是实际距离标定。拖动旋转视角、滚轮缩放。当前目标、模型状态与安全状态在画面周围说明。

## 轮椅动作
LEFT左转30度，RIGHT右转30度，FORWARD沿当前朝向前进0.8演示单位，STOP保持位置和朝向。患者和脑电帽共同跟随，轮子仅随位置或朝向变化转动，停止后不会按动画时间继续走。

## 护理床、呼叫、家居
护理床LEFT靠背下降5度，RIGHT或FORWARD上升5度，范围0到60度。紧急呼叫的有效方向命令置为已呼叫；家居LEFT关闭灯光，RIGHT或FORWARD开启灯光。STOP停止继续执行但保留当前床角度、呼叫或灯光状态。重置恢复所有模拟设备的初始姿态。

## 设备与故障演示
创建会话后在3D区域或设备卡片选目标。更换目标会停止当前动作并清除候选确认，需重新满足闭环。设备卡片可切换在线、离线、忙碌、执行失败、延迟、丢包、超时场景，查看停止与告警。浏览器不支持WebGL时仍可使用设备卡片操作并查看数值状态。
