# 控制工作台操作指南

## 按顺序操作
先登录并选择或创建用户，再选择来源、完成个体化校准，准备同一用户、同一来源、同一通道布局的EEG实验与配对EOG。创建会话，选择模拟设备，点击开始，观察EEG意图、EOG确认、安全决策与3D回执。暂停后可以继续；回放完成需重置；关闭会话后可以更换用户或来源。

## 内置来源
后端有A01的3通道、22通道及A02的3通道、22通道四种来源，缺失者显示未准备。校准来自对应受试者T会话40条，回放来自E会话24条。A01眼电为另一个公开数据集的离线配对片段，用于双眨眼闭环展示，不是该EEG的同步生理采集。A02眼电来自同一EEG原文件的眼电通道，未独立验证眨眼标签，可能不触发确认。

## EEG校准上传格式
NPZ只含X和可选y。X形状(N,3,501)或(N,22,501)，N至少2、250Hz、微伏、全部有限。3通道顺序C3/Cz/C4；22通道顺序Fz/FC3/FC1/FCz/FC2/FC4/C5/C3/C1/Cz/C2/C4/C6/CP3/CP1/CPz/CP2/CP4/P1/Pz/P2/POz。压缩不超过20MiB、解压不超过64MiB。y为长度N的整数0..3；有标签校准每类至少10条。无标签保存EA参考，有标签另训练个人CSP/LDA。

## 同源回放与EOG上传
EEG回放NPZ使用同一X格式，y可选，不得重复校准trial。用户、来源标识与通道布局必须一致，默认上传来源标识default。上传者须保证实际身份、采样率、单位、通道顺序和配对正确，系统不能证明生理同源。EOG上传NPZ只含X，形状(N,501)或(2N,250)，N等于EEG trial数，250Hz、微伏、有限且窗口非恒定，压缩不超过16MiB。已滤波选项仅用于已做1–15Hz带通的数据。活动会话期间禁止替换输入。无EOG可看EEG推理，但不能产生移动确认。

## 常见问题
没有档案先校准，没有实验先准备同源数据。开始按钮需要会话存在且实时连接正常。换用户或来源先关闭会话。急停锁定后需重置。置信度不足、不稳定、无双眨眼确认、离线、忙碌、超时均维持STOP。不能手工伪造眨眼模型确认。
