# Neural Core 沉浸交互增强验收

2026-09-29，本次在既有首页基础上增强视觉张力和即时反馈。中文叙事仍以实际项目的个体化 EEG 校准、四类运动意图、EOG 眨眼确认、安全控制与辅助设备仿真为准。

## 实现

- 大型程序化神经核心：内部发光、神经点云、连接网络、曲线纤维、外层粒子、缓慢轨道与沿线传播脉冲。青蓝扫描每 7.5 秒穿过核心，扫描区域的节点、连接和粒子变亮。
- 鼠标位置经过阻尼，控制核心视角、相机、背景视差和局部光晕。顶点着色器实现局部排斥与波纹，离开鼠标后平滑恢复。
- 中文标题逐字进入，副标题延迟、核心模糊缩放、CTA 最后进入；入口动画约 1.4 秒。正文与 SVG 静态神经图随 HTML 先行显示，3D 异步加载。
- 磁性 CTA 与文字偏移、点击压缩回弹、导航下划线、图标发光、卡片轻微倾斜与局部光晕、滚动提示和流程编号呼吸效果。
- 桌面 Hero 使用粘性舞台。滚动先向核心靠近，再将同一组点云和连接线重组为 EEG → Intent → EOG → Device 四个节点，标题与标签同步移动，随后自然进入 How It Works。不可见 CTA 不再接受点击。
- 移动端和减少动态模式使用连续内容布局，避免长时间粘性舞台；无 WebGL 2 时在初始化前检测并显示 SVG，页面保留文案、入口、节点及正文。

## 性能与实现边界

Three.js 更新统一放在 React Three Fiber `useFrame`；鼠标/滚动使用共享 ref 与 shader uniforms，没有逐帧 React state 更新。DOM 微交互使用独立的休眠式 RAF，交互结束后停止。3D 离屏、页面隐藏、暂停或减少动态模式时停止持续绘制；卸载时释放几何、材质及后处理资源。

桌面 2480 个节点/外层粒子，低性能或手机设备 1010 个；桌面 DPR 上限 1.4、移动端 1。桌面 Bloom 使用较低分辨率；连续两个低帧率窗口关闭 Bloom 并降低 DPR。后台限帧样本不作为 GPU 性能不足，恢复前台时同步滚动进度，避免旧场景与正文错位。没有新增依赖或加载 GLB。

## 本地验收

| 检查 | 结果 |
| --- | --- |
| 1920×1080、1440×900、1366×768 | 内置 Chromium 实际布局尺寸确认，标题、CTA、核心与流程可见，无横向溢出 |
| 390×844、375×812 | 无横向溢出，1010 粒子、DPR 1、关闭 Bloom；采用手机连续布局 |
| 鼠标反馈 | 局部核心光晕与粒子响应、背景视差、CTA 偏移、卡片倾斜的实际 DOM/场景参数检查通过 |
| 滚动叙事 | 实际场景 morph 达到 1.000，四组神经节点与对应标签完成重组，下一节保留四阶段说明 |
| 暂停与节点 | 暂停/继续按钮状态及节点中文/英文说明可用 |
| 无 WebGL | 本地专用服务禁用 WebGL 上下文，显示静态 SVG；没有 Canvas、没有控制台错误，中文标题与 CTA 保留 |
| 减少动态效果 | 本地专用服务模拟系统偏好并启用对应 CSS；静态绘制，Bloom 关闭，标题无动画，滚动 morph 为 0 |
| 页面刷新 | 生产静态导出多次刷新可显示中文正文与真实 3D，无白屏 |
| 构建/类型/ESLint | Next.js 生产静态导出、TypeScript 与本次所有 TS/TSX 修改文件的 ESLint 通过 |

当前电脑内置浏览器前台采样约 132–144 FPS（144 Hz 环境）；该结果仅代表当前设备。测试服务中缓存资源、未限速的 FCP/LCP 为 460 ms，3D ready 为 1443 ms；不代表冷缓存、弱网或公网 SLA。首页 HTML 136411 字节、gzip 37850 字节。R3F 内部使用 Three.Clock 会产生依赖弃用警告，正常场景没有运行错误。

Chrome 扩展未连接，经用户同意使用 Codex 内置浏览器；独立 Chrome 和真实手机 GPU 尚未实测。手机尺寸检查不等同实际手机性能基准。测试注入与截图仅存放在忽略目录 `temp/`、`output/hero-immersion/`，不进入发布包。全页截图可能受浏览器拼接影响，移动验收以分屏截图及实际 DOM 尺寸为准。

## 发布方式

使用 `deploy/update-frontend.sh` 从当前 `/opt/als-bci/releases/security-4e68fed` 复制发布目录，仅覆盖本次前端源码和静态导出，保留原后端、数据库、模型与环境。旧哈希资源保留供已打开工作台使用。原子切换后校验并 reload Nginx，使 CSP 脚本哈希与新 HTML 同步；失败回滚路径同样重新加载原 CSP。后端服务不重启。

发布前后检查后端 Python 源码校验值、MainPID、首页与静态资源、API 健康和四类账号的登录/当前用户/运行中心访问。正式发布结果在完成后追加。
