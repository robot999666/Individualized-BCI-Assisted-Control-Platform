# 首页 Neural Core 优化验收

2026-09-29。变更集中于首页 Hero；首页下方内容、导航锚点、工作台、运行中心、API、登录及模型逻辑保持原实现。中文为主要展示语言，英文仅用于技术术语与辅助标识。

## 视觉与交互

- 程序生成双半球神经点云、皮层纤维、局部连接和内部脉冲，无外部模型、纹理或字体下载。
- EEG 波形与信号流进入神经核心；眼电确认与设备控制节点展示输出路径。画面明确标注“流程概念可视化”，不冒充实时患者信号或真实设备连接。
- 沿用青绿色品牌强调色，搭配青蓝与少量紫色；暗色渐变、低密度中景节点、前景核心形成深度。桌面轻量 Bloom，CSS 实现 Vignette 与细微 Noise。
- 场景区域内鼠标视差、轻微旋转和粒子扰动；节点支持鼠标、触摸与键盘，显示中文说明和英文术语。提供动画暂停按钮。

## 性能与限制

正文、中文 CTA、神经 SVG 预渲染为 HTML；Three.js 与桌面后处理在浏览器空闲时异步加载，不阻塞正文。桌面 2600 粒子、DPR 上限 1.6；低配置设备减少粒子、关闭 Bloom。两次连续低帧率样本会先关闭 Bloom、降低 DPR；后台浏览器调度间隔不计为 GPU 性能不足。离屏、隐藏页面或用户暂停时停止持续渲染；卸载释放 GPU 资源。原有工作台的 3D 逻辑没有改动。

内置浏览器前台曾记录约 143 FPS（144 Hz 显示环境），超过桌面 60 FPS 目标；后台浏览器会被限帧，不作为设备基准。此结果仅代表当前电脑，移动布局测试不等同真实手机 GPU 测试。独立本地性能页面首轮 FCP/LCP 为 1276 ms，未模拟弱网；不作为公网或所有设备的加载承诺。首页 HTML 约 128 KB，gzip 约 36 KB；没有新增 npm 依赖或 GLB 资产。

截图位于本地忽略目录 `output/hero/`。无 WebGL、减少动态效果及性能注入只存在于 `temp/` 本地验收服务，不进入正式页面或发布包。

## 发布与回滚

使用 `deploy/update-frontend.sh` 从当前已验证版本复制新发布目录，合并本次前端源码与静态产物，原子切换 `/opt/als-bci/current`。后端、私有环境、数据库、模型与用户数据沿用旧版本，不重启业务服务；保留旧哈希资源供已打开的工作台使用。

`FRONTEND_RELEASE_COMMIT` 记录前端版本，`RELEASE_COMMIT` 保留原后端发布标识，`PREVIOUS_FRONTEND_RELEASE` 记录回滚目录。切换后检查首页标识、HTTPS 健康接口及 Nginx/后端服务状态，失败时自动切回旧目录。公网补充验收使用原账号验证登录、当前用户和运行中心访问，只输出状态，不输出密码或业务记录。
