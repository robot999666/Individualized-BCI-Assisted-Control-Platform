# 控制工作台检查与修复验收

日期：2026-09-27；本地工作区：D:\recent\web；验证环境：Windows、Python3.12、MySQL、Next.js16.3.1。

## 用户操作

1. 创建或选择用户。访客选择内置演示来源；研究人员和管理员也可创建私有研究用户。
2. 选择内置来源并执行校准，或上传私有校准NPZ。可复用该用户已保存的档案。
3. 准备所选来源的演示数据，或上传同一用户、同一采集来源、同一通道的独立回放NPZ。私有实验可上传配对EOG并声明滤波状态。
4. 创建会话，待“实时连接正常”后点击开始。EEG生成意图和概率，连续稳定且达到阈值后，EOG两个不同眨眼峰确认有效候选，安全控制器下发命令，模拟器返回ACK。
5. 暂停后设备停止、游标冻结；继续从当前位置回放。人工急停或模型异常锁定停止，须重置后继续。回放结束立即停止设备。
6. 更换用户、来源、档案或EOG文件前关闭会话。工作台记录按当前会话过滤；运行中心查看授权范围内的历史。

## 发现并修复的问题

- 只有硬编码A01 3ch来源，且私有用户看到不适用的演示按钮：加入四套服务端来源目录，界面按用户类型显示入口。
- 仅按用户和通道配对，无法阻止同一用户下不同来源混用：校准、会话和评分统一检查source_id，并兼容旧记录。
- 运行中切换用户、新建用户或重复提交可能保留旧会话：锁定设置，提交互斥，校验新输入成功后再替换旧会话。
- 暂停后可能继续消化积压样本；重置、急停或撤销时旧推理可能覆盖新状态：暂停冻结，服务端generation使过期结果及写入失效，客户端拒绝旧generation帧。
- 回放结束未立即停止运动；手工急停状态与累计时间不完整：完成即STOP，急停持久记录来源并同步暂停状态。
- WebSocket认证只在连接时检查：流中重新验证账号；退出、撤销和权限变更关闭并释放相关会话。
- 本地preview不代理WebSocket，依赖缺少WebSocket协议库：增加Upgrade代理，固定websockets依赖，并通过真实Uvicorn和浏览器验证。
- 模拟器返回顺序随数据库主键变化：当前控制设备优先，避免故障场景测试或操作选错目标。
- 私有EOG允许上传恒定/非数值窗口或会话运行期间替换文件：增加窗口验证与活动会话保护。
- 当前工作台混入同账号其他用户/实验记录：operations支持授权检查后的session_id过滤。
- 管理员修改禁用账号角色会意外启用，且无法恢复账号：显示启停状态、保留现有active值、支持重新启用。

## 结果口径

EEG和EOG是实际模型计算，设备和ACK为模拟。置信度、计算延迟与模拟设备延迟分别展示，不将置信度宣传为准确率。A01为明确声明的离线EEG/EOG片段配对闭环演示；A02为原始文件同步EOG且不保证眨眼确认。上传来源和同步关系由上传者声明，不能自动证明生理身份、单位或采样率。带标签回放仅提供本次描述性评分，不宣称独立泛化或临床有效性。
